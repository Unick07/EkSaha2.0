# EkSaha Logo Brand Kit

Version: 2026-07-29

This archive contains the approved EkSaha logo family. The master SVG files are fully vectorized, transparent, font-independent, and suitable for long-term storage.

## Master SVG files

- `eksaha-horizontal-adaptive.svg` — preferred horizontal logo; automatically adapts to the system color scheme.
- `eksaha-horizontal-dark.svg` — horizontal logo with light primary shapes for dark backgrounds.
- `eksaha-stacked-adaptive.svg` — preferred stacked logo; automatically adapts to the system color scheme.
- `eksaha-stacked-dark.svg` — stacked logo with light primary shapes for dark backgrounds.
- `eksaha-icon-adaptive.svg` — preferred square icon and favicon master.
- `eksaha-icon-dark.svg` — square icon with light primary shapes for dark backgrounds.

## PNG files

The `png` directory contains transparent high-resolution exports for software that cannot use SVG.

The `favicon` directory contains transparent 16, 32, 48, 64, 128, 256, and 512 px icon exports.

## Brand colors

- Navy: `#051C3C`
- Teal: `#0FA89E`
- Dark-theme light: `#F4F7FA`

## Usage

- Prefer SVG whenever possible.
- Use adaptive files for websites and applications that support SVG media queries.
- Use the dark files on navy, black, or other dark backgrounds.
- Preserve the original aspect ratio and clear space.
- Do not add shadows, gradients, outlines, or change the relative position of the ring, square, monogram, or wordmark.
- The `ES` monogram intentionally has no separator dot.

## Recovery location
